# Particles

Інтерактивна симуляція часток на GPU (Three.js, без збірки). Кожна з ~150 тис. частинок має власну позицію й швидкість і живе за фізикою: гравітація планет, орбітальні смуги, взаємне притягування/відштовхування, камера, годинник.

## Запуск

```bash
python3 -m http.server 8000
```

Відкрийте http://localhost:8000 у **звичайному браузері** (Chrome/Safari/Firefox). Деплой: будь-який статичний хостинг (GitHub Pages, Netlify, Firebase Hosting): віддавайте папку як є. Three.js підтягується з CDN.

## Що вміє

- **Три планети** (бірюзово-фіолетова, жовто-червона, сіро-біла). Планети можна **перетягувати мишею**; поки тягнете, їхні частинки втрачають гравітацію, а після відпускання повертаються.
- **Повзунки «Свої / Чужі»** для кожної планети, від −150 до +150 з нулем посередині: вправо сила притягування, вліво сила відштовхування. «Свої» діє на власні частинки, «Чужі» на частинки інших планет. Подвійний клік по повзунку повертає початкове значення.
- Частинка тримається планетою, що притягує її найсильніше; жорсткі межі: не ближче `R_MIN` і не далі `MAX_SPREAD` радіусів.
- **Камера** («Камера: малювати мене»): частинки малюють ваше обличчя й шукають на відео ділянки свого кольору (жовті до теплих тонів, сині до синіх). «Лише обличчя» обмежує ефект обличчям (детектор MediaPipe, запасний варіант за кольором шкіри). «Режим: тіні» показує лише тіні, тобто контур. Працює лише у звичайному браузері на `localhost` або HTTPS; відео не залишає ваш браузер.
- **Годинник-скрінсейвер** («Годинник», клавіша `C` або `?clock=1`): цифри часу працюють як планета: частинки падають до них, збираються в смугу навколо контуру й кружляють уздовж нього. Подвійний клік вмикає повноекранний режим.
- Панелі керування самі ховаються через 5 секунд бездіяльності. Є автоматичне регулювання якості за FPS.

## Параметри в адресі

| параметр | дія |
|---|---|
| `?clock=1` | почати як годинник-скрінсейвер |
| `?camtest=1` | синтетичне відео замість камери (для перевірки) |
| `?detector=skin` | пошук обличчя за кольором шкіри без MediaPipe |
| `?adaptive=0` | вимкнути автоякість |
| `?range=2` | зона дії планети на чужі частинки (у разів) |

## Налаштування (початок `main.js`)

`SIZE` (кількість частинок = `SIZE²`), `GRAVITY`, `R_MIN`/`R_MAX`, `MAX_SPREAD`, `REPEL_K`, `FOREIGN_RANGE`, `PAIR_GAP`, `STATIC_PAIR` (`false` вмикає динамічну систему з польотами планет).

## Файли

- `index.html`: сторінка та стилі керування
- `main.js`: уся симуляція та шейдери
